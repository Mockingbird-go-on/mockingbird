# Changelog

Формат версии: `MAJOR.UI.BACKEND.FIXES` (4 компоненты). Дата — дата релиза.

## 1.0.5.0 (2026-10-03)

### Надёжность загрузки моделей

- **s3.cloud.ru — первичный источник**: модель скачивается из бакета
  `mockingbird` (все 5 размеров), GitHub-релиз и HF CDN — fallback'и.
  Полный прогресс, отмена, детект обрыва (Content-Length vs done,
  tolerance 10 МБ), 3 ретрая с backoff.
- Flight-lock в `resolve_model_path` освобождается на любом выходе
  (раньше утекал при раннем return).
- Оверлей скачивания: скорость/ETA/МБ, центрирование, не крадёт фокус;
  «Проверка системы» поверх оверлея; ActivityBar сбрасывается на ready.

### Пайплайн импорта резюме (аудит B2–B10)

- `reload_kb` маршалится в GUI-поток через сигнал-мост (раньше прямой
  вызов из worker-потока — гонка с Qt).
- Кнопка «Удалить» блокируется на время импорта; QThread-lifecycle
  (hard-ref, wait перед реюзом, deleteLater); closeEvent ждёт импорт.
- LLM не настроен → внятная ошибка вместо тихого пустого результата.
- reasoning-модели: `reasoning_content` принимается только при валидной
  YAML-схеме; `max_tokens>=6000` + streaming-retry + halving чанков при
  `finish=length`; сбой одного чанка не теряет топики остальных;
  специфичные сообщения об ошибках (token budget / content_filter /
  transport).

### UI

- Краш `capture-affinity` eventFilter на QWindow (`isWindow`) — guard по
  `isinstance(obj, QWidget)`.
- Onboarding: Enter в QLineEdit корректно переходит на следующий шаг
  (раньше QDialog принимал accept и рестартовал визард); «Пропустить» на
  шаге LLM работает при пустых полях.
- Онбординг-коннект-чек асинхронный (QThread), иконки статуса —
  стандартные QStyle вместо эмодзи.

### Документация

- README_EN.md / README_ES.md — полные переводы с языковым
  переключателем; улучшения README (hardware requirements, FAQ, фичи).

### Режим «Тест» и скриншоты

- Мгновенный фидбек скриншот-вопроса: вопрос сразу появляется в «Истории»
  и шапке, в «Ответ ИИ» — «Формирую ответ ИИ…» (не ждём LLM-раундтрип).
- Закрытие оверлея Тест-режима больше не замораживает GUI на 5 с: join
  in-flight LLM-воркера перенесён из `stop_test_mode` в `start_test_mode`.

### Смена темы

- Краш `AttributeError: _regenerate_btn` при переключении темы починен
  (кнопка живёт во внутреннем `_AnswerPane`, `retheme` делегирует туда).
- Рамка QGroupBox на вкладке «Резюме» теперь реально красится: в inline
  stylesheet'e была лишняя `}` (Qt молча ронял всё правило) и
  `palette(mid)`, ломающий парсер.
- Кнопка регенерации ответа, вкладка «Резюме» (карточка, hint, статус)
  перекрашиваются при смене темы.

## 1.0.4.0 (2026-09-30)

### Интернационализация (RU/EN)

- Новый языковой переключатель: Настройки → Внешний вид → «Язык интерфейса»
  (Русский / English). Применяется после рестарта — индустриальный стандарт,
  полный live-retranslate всех виджетов слишком хрупок.
- Онбординг: на шаге 0 появился селектор «Язык интерфейса / Interface
  language» — выбор сохраняется в `QSettings ui/lang`, дальнейшие сессии
  стартуют на выбранном языке. Переключение языка внутри визарда
  пересобирает все страницы «на лету» (включая авто-плейсхолдеры и
  подсказки), но без потери введённых данных.
- LLM-промпты переведены на английский: 5 системных инструкций
  (technical / personal / mixed / behavioral / concept) теперь имеют
  EN-вариант, выбирается через `i18n.current_language()`. Служебные JSON
  промпты (терм-детект, context-tracker) сохраняют RU-схему и при EN
  режиме получают хинт «Respond in English, keep JSON keys exact».
- Инсталлятор: добавлен английский язык в `[Languages]` (Russian + English),
  Inno показывает диалог выбора при первом запуске. CustomMessages для
  диалога удаления данных — кириллические, привязаны к языковому ключу
  `russian.*`.
- Словари: `src/mockingbird/assets/lang/en.json` (UTF-8) — ключ = русский
  исходник, значение = перевод. 207 ключей переведено с учётом контекста
  (онбординг, настройки, диалоги, уведомления, LLM-промпты-плейсхолдеры).
- Fallback: отсутствующий перевод возвращает русский ключ — RU-сборка
  работает без `en.json`.

### Изменения версии и тестов

- Версия поднята до `1.0.4.0` (минорный UI-релиз — накопительный объём
  RU/EN + переключатель заслуживает инкремент).
- `tests/test_i18n.py` — fallback / placeholders / валидность JSON /
  защита от Cyrillic в EN-значениях.
- `tests/test_packaging_scripts.py::test_iss_has_ru_and_en_languages_and_utf8_bom` —
  инвариант Inno.

### Архитектура

- `src/mockingbird/i18n.py` — `t(key, **kwargs)`, `set_language(code)`,
  `current_language()`, `detect_language()`, `load_initial_language(qs)`,
  `placeholders(text)`. Словари загружаются через `importlib.resources`,
  работают в editable и PyInstaller.
- `pyproject.toml` + `scripts/mockingbird.spec`: `lang/*.json` в
  package-data и datas.

## 1.0.3.0 (2026-09-30)

### UI/UX

- Onboarding: убраны текстовые стрелки с кнопок навигации, автоподсказки
  популярных LLM-моделей (DeepSeek/GPT/Claude/Gemini и др.) в поле «Модель»,
  шаг «База знаний и внешний вид» удалён (тёмная тема + защита от захвата
  экрана включены по умолчанию).
- Тулбар: кнопка скриншота перенесена к «Настройкам»; статус-пилюля и бейдж
  GPU/CPU объединены в одну («GPU · large-v3-turbo»), вместо надписи
  «running» — мигающий зелёный индикатор.
- Радиусы скругления всех элементов интерфейса уменьшены вдвое.
- Диалог «Проверка системы» показывается через 10 с после запуска, а не
  поверх сплэш-лоадера.
- Эмодзи в статусах (✅/⬜/❌) заменены на нативные Lucide-иконки
  (Настройки → LLM, вкладка «Резюме»).

### Скриншот-вопросы

- Перегенерация ответа по скриншоту повторно отправляет изображение +
  текст вопроса (раньше — только текст, LLM терял картинку).
- Пустое поле вопроса подставляет дефолтный промпт «Распознай текст на
  экране…»; диалог закрывается сразу после отправки.
- Vision-проба использует валидное изображение 4×4 (DeepSeek отвергал
  probe 1×1 как «unsupported image» → кнопка скриншота ошибочно гасла);
  результат сбрасывается и перепроверяется после смены модели в Настройках.

### Инсталлятор

- Брендированный визард: баннер 164×314 + миниатюра 55×58 из логотипа.
- Тёмная тема инсталлятора в корпоративных цветах (#1A1D21 / #d1d9e1):
  фон, текст, поля ввода и кнопки перекрашены рекурсивно.

### Надёжность (аудит гонок, ветка audit-ux-race-fixes)

- 11 фиксов race conditions: rollback половинной сессии, утечка
  stop-worker, ретраи скачивания с живым cancel, гонки сегментного
  состояния whisper, generation-guard, early-exit при остановке и др.
- shutdown() не теряет последний сегмент сессии (wait_flush перед stop).

## 1.0.2.1 (2026-09-24)

### Исправления

- Зависание оверлея «Загрузка модели распознавания» на 99%: если окно
  приложения теряло фокус во время скачивания, оверлей не финализировался
  и воскресал навсегда при возвращении в приложение.
- Все размеры whisper-моделей (tiny / base / small / medium / turbo)
  зеркалированы в GitHub-релизе `models` — скачивание работает и при
  недоступном CDN huggingface.co (корп. прокси). `large-v3` убрана из
  списков выбора (не зеркалируется: 3.1 ГБ > лимита GitHub 2 ГиБ; turbo
  даёт то же качество в 6–8 раз быстрее).
- CPU-сборка больше не показывает бесполезный диалог «GPU недоступен»
  и не тратит ~20 с на CUDA-probe; `whisper.device` нормализуется в `cpu`.
- Qt-логгер диагностики падал с AttributeError на каждое предупреждение
  PySide6 (QMessageLogContext API).

## 1.0.2.0 (2026-09-24)

### Новое

- **Скриншот-вопрос (screenshot-to-answer)**: глобальный хоткей
  `Ctrl+Shift+S` или кнопка 📷 в тулбаре → выделите область экрана →
  задайте вопрос → ответ стримится в панель «Ответ ИИ» как обычный ответ.
  Скриншот, вопрос и ответ сохраняются в истории сессии (таблица
  `screenshots`, изображения — `~/.mockingbird/screenshots/`).
  Поддержка изображений текущей моделью проверяется автоматически
  (1×1 px probe); при отсутствии vision — понятное сообщение.
  Настраивается: `MOCKINGBIRD_SCREENSHOT_ENABLED`, ограничение размера
  1600 px / JPEG q80 (пакет `ui/screenshot.py`, `LlmClient.probe_vision`
  / `answer_image_question_stream`).

### Исправления

- Тулбарный индикатор «Loading model into memory…» не сбрасывался после
  готовности модели (вечный спиннер).
- Ложное срабатывание stall-watchdog при живом скачивании в Windows-сборке:
  теперь перед отменой проверяется рост `*.incomplete`-файлов на диске.
- Первое нажатие «Старт» ошибочно считало живой warm-start воркер
  «зависшей остановкой» (30 с ожидания + RuntimeError) — воркер
  переиспользуется.
- Модальный диалог при неудачном старте сессии (раньше — только статусбар).
- Диалог «Проверка системы» больше не перекрывается оверлеем загрузки
  модели; оверлей центрирован и скрывается, когда приложение неактивно.

## 1.0.1.0 (2026-09-22)

Первый публичный релиз. Ниже — сводка изменений относительно 1.0.0.0.

### Новое

- **Отмена загрузки модели на всех фазах**: маленький крестик в тулбаре
  прерывает не только скачивание, но и фазу «Loading model into memory…»
  (загрузка весов + CUDA-проба) — раньше выхода из этой фазы не было.
- **Диалог скачивания модели**: честный прогресс в процентах, скорость/время,
  кнопка «Отмена», докачка после обрыва (resume), 3 повторные попытки.
- **Оффлайн-установка**: Silero VAD вшит в дистрибутив; пак модели
  (`Mockingbird-whisper-large-v3-turbo-model.zip`) кладётся рядом с
  инсталлятором (`cache/`) — модель копируется автоматически, без сети.
- **Русскоязычный инсталлятор** без лишнего шага выбора языка; корректное
  удаление (завершение запущенного приложения, очистка `{app}`,
  вопрос про пользовательские данные в `~/.mockingbird`).
- **Диагностика**: при падении приложение предлагает собрать архив логов
  (окружение + замазанные ключи API + ротированные логи).
- **Сборка**: единый вход `scripts/build.sh` (`win-gpu|win-cpu|linux|model-pack|all|publish`),
  разделение релиз-артефактов (каждый < 2 ГБ), контрольные суммы SHA256.

### Улучшения

- Производительность пайплайна: типовой вопрос ~5–6 с (было ~13.6 с);
  прогрев CUDA при старте; инкрементальное чанк-декодирование; кэш
  фонетического матчинга (×60 на miss-токенах).
- Качество распознавания: hotwords-промпт (декодер-левел bias), пост-коррекция
  терминов, LLM-коррекция длинных финалов, адаптивный VAD-порог,
  детект вопросов (implicit + LLM rescue), слияние «хвостов» вопросов.
- Режим «Созвон» (Call Advocate) удалён; приложение сфокусировано на интервью:
  вкладки «Интервью», «Резюме» (PDF → база знаний), «Лог».
- GigaAM-бэкенд удалён; единственный движок — faster-whisper
  (large-v3-turbo по умолчанию); старые конфиги тихо мигрируют.
- Linux: AppImage + .deb, loopback через PulseAudio/PipeWire-мониторы.

### Исправления

- 20+ кросс-платформенных багов (crash/hang: watchdog, stop/start, VAD-prefetch,
  shutdown; degraded: блокировки, повтор snapshot, зависимости).
- CUDA-стек пиннут к 12.4 (nvrtc 12.9 требует драйвер ≥575 → «CUDA недоступна»).
- Дедупликация CUDA-DLL в дистрибутиве (~4.1 ГБ → ~2.2 ГБ), исправлена
  вложенность DLL-каталогов («Library cublas64_12.dll is not found»).
- Настройки: `apply()` больше не падает до применения темы; онбординг
  спрашивает модель/LLM до скачивания по умолчанию.
